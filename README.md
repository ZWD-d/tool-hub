# Tool Hub · 下载工具

中文网页下载工具：输入公开 HTTP/HTTPS 文件直链，服务端下载后显示进度，并提供保存、取消与清理操作。

## 开发运行

需要 Node.js 24.5 或更高版本，无第三方运行依赖。

```sh
npm ci
npm test
npm start
```

浏览器访问本机 3000 端口。默认只监听 `127.0.0.1`；可用 `PORT` 修改端口。`HOST` 可修改监听地址，但该工具无用户认证，仅适合个人可信环境，勿直接暴露到公网。

## 范围与限制

- 最多 3 个并发任务、100 个保留任务，单文件上限 1 GiB；30 秒无响应或 30 分钟总时长会终止下载。
- 支持最多 5 次重定向，每次重新验证目标并固定解析地址；拒绝本机、私有及保留 IPv4 地址、IPv6 和非标准端口。
- 不支持登录、Cookie、网页视频解析、断点续传或代理认证。下载仅针对直接返回文件的链接。
- 文件保存在被 Git 忽略的 `downloads/`。任务列表只保存在内存，重启后消失；请在重启前保存并清理任务，残留文件可在服务停止后手动删除。
- 普通模式需要到目标站点的 DNS 和网络访问。云环境通过已有 `HTTP_PROXY` / `HTTPS_PROXY` 访问外网时，必须用 `DOWNLOAD_ALLOWED_HOSTS` 指定可信公开域名（逗号分隔，不支持通配符），包括重定向目标。代理模式由代理解析 DNS，仅允许列表中的域名；不要加入内部域名或不可信 DNS 域名。环境网络策略也必须允许目标域名。

云环境启动示例（这两个公开域名已验证可访问）：

```sh
DOWNLOAD_ALLOWED_HOSTS=registry.npmjs.org,raw.githubusercontent.com npm start
```

测试使用本地模拟远端验证文件内容、任务状态、取消、清理、上限及请求校验，不依赖外网。
